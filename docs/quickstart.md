Щоб усе запрацювало, потрібно підняти три речі: базу, сервер і застосунок.

## Що потрібно

- .NET SDK, Android Studio з емулятором, акаунт MongoDB Atlas.
- Для перегляду бази зручно мати MongoDB Compass.

## 1. База даних

1. Створіть безкоштовний кластер **M0** в MongoDB Atlas.
2. У розділі *Database Access* створіть користувача бази (логін і пароль, це не акаунт Atlas).
3. У розділі *Network Access* дозвольте доступ зі своєї адреси (для навчання підійде `0.0.0.0/0`).
4. Скопіюйте рядок підключення (*Connect → Drivers*).

## 2. Сервер

У `appsettings.Development.json` вкажіть підключення (цей файл не додавайте в git):

```json
{
  "MongoDbSettings": {
    "ConnectionString": "mongodb+srv://ЛОГІН:ПАРОЛЬ@кластер.mongodb.net/?appName=MotoMongo"
  }
}
```

Запуск:

```bash
cd MotoEngine_back
dotnet run
```

Відкрийте `http://localhost:5045/swagger`. Якщо бачите список ендпоінтів, сервер працює.

## 3. Початкові дані

База спочатку порожня. Створіть у базі `MotoDiagnosticsDb` колекції `symptoms` і `rules` та імпортуйте початкові ознаки й правила (через Compass: *Add Data → Insert Document* або імпорт JSON-масиву). Формат записів описано в розділі [API](api.md).

## 4. Застосунок

1. Відкрийте проєкт в Android Studio.
2. У `NetworkModule.kt` переконайтесь, що адреса збігається з портом сервера:

```kotlin
private const val BASE_URL = "http://10.0.2.2:5045/"
```

> `10.0.2.2` — це адреса вашого комп'ютера з емулятора Android. На справжньому телефоні потрібна IP-адреса комп'ютера в локальній мережі.

3. Запустіть застосунок (**Run**). Після зміни залежностей зробіть *Build → Rebuild Project*.

## Перевірка

Відкриється вкладка «Діагностика» з картками сфер. Якщо картки є, застосунок бачить сервер, а сервер бачить базу. Якщо ні, дивіться [Часті питання](faq.md).
