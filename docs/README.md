**Експерт-діагност** — експертна система для пошуку несправностей мотоцикла. Ви відповідаєте на кілька простих питань («Стартер крутить?», «Є іскра?»), а система сама добирає наступне питання і наприкінці називає ймовірну причину та пояснює, чому вона так вирішила.

## Що вміє система

- **Діагностика у вигляді діалогу.** Питання ставляться по одному, відповіді «Так», «Ні» або «Не знаю».
- **Гіпотези на льоту.** Під час діалогу видно, які версії несправності зараз найбільш правдоподібні.
- **Пояснення висновку.** Кожен діагноз супроводжується рядком «Чому: …» з підтвердженими ознаками.
- **Редактор бази знань.** Нові ознаки та правила додаються прямо із застосунку, без зміни коду.

## З чого складається

| Частина | Призначення | Технології |
|---|---|---|
| Мобільний застосунок | інтерфейс діалогу та редактор | Kotlin, Jetpack Compose, MVVM, Hilt, Retrofit |
| Сервер | логіка виводу та API | ASP.NET Core, Swagger |
| База знань | ознаки та правила | MongoDB Atlas |
